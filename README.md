# project-arche
From-scratch cognitive architecture: grounded intelligence from embodiment and prediction error without pretraining or backprop.

# Welcome to Project Arche (Ar-Kay)!

Project Arche asks one question: **what is the foundational principle of grounded intelligence?**

Arche defines grounded intelligence as embodied cognition paired with physical experience. A mind occupying a body, inhabiting a world, and developing a model of that world over time.

Transformer architecture is fundamentally incompatible with this concept, yet we are reaching for human intelligence as a benchmark.

This project bets that benchmark will only be reached by a system built the same way we were.

## Core Functionality

A fully detailed explanation is available in the Architecture documentation, but the human readable version is this:

Arche wakes up in a body, in a world, knowing nothing.

Every moment, it tries to predict what happens next through seeing, hearing, or feeling. Then reality happens, and Arche compares what it predicted to what actually occurred. The gap between the two is the only teacher it ever gets.

When the prediction is wrong, the system adjusts. Arche is never told the right answer. Instead, it quietly reshapes itself so it’s a little less wrong next time. Do that millions of times, against honest physics that never lies, and structure starts to form. The system learns that objects fall, that surfaces resist, that some things are caused by its own body and some are not.
